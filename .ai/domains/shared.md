# Dominio: Shared — SOLO EQUIPO DE ARQUITECTURA

> ⚠️ Este dominio solo puede ser modificado por el equipo de Arquitectura (3 personas).
> Si necesitás algo de shared, abrí un issue o hablá con el tech lead.

## Podés modificar
- `libs/shared/**`
- `apps/**`
- `tsconfig.base.json`
- `.eslintrc.json`
- `nx.json`

## Proceso para cambios en shared
1. Abrir issue describiendo qué necesitás y por qué
2. El equipo de Arquitectura evalúa y aprueba
3. Se crea la rama `chore/shared/descripcion`
4. PR requiere 2 aprobaciones (incluyendo tech lead)

## Scope
`chore/shared/...` | `feat/shell/...` | `fix/shared/...`
